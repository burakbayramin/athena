    ```
    pub struct AgentCoordinator {

    }
    ```

    Implement:
    - new(registry: AgentRegistry, output_dir: PathBuf, git: Option<AsyncGitLayer>) -> Self
    - async fn run_plan(&self, plan: &ExecutionPlan) -> Result<Vec<PhaseRecord>, PhaseRunnerError>

    run_plan logic:
    1. Collect results: Vec<PhaseRecord>
    2. For each phase_id in plan.execution_order:
       a. Find PhaseSpec by id from plan.phases
       b. Build write_files closure that writes FileOutputs to output_dir (create parent dirs, write content)

       d. Call run_phase(phase, &self.registry, available, write_files, self.git.as_ref())
       e. On Ok(record): push to results
       f. On Err: return error (fail-fast per Phase 6 pattern). Attach partial results via error context.
    3. Return results
