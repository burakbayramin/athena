3. Create crates/ath-git/src/error.rs:
   - GitError enum using thiserror with variants:
     - `RepositoryOpen { path, source: git2::Error }` -- failed to open/init
     - `DirtyWorkingTree { hint: String }` -- uncommitted changes present
     - `MergeConflict { hint: String }` -- index has conflicts
     - `FileMissing { path: PathBuf, hint: String }` -- declared file not on disk and not previously tracked
     - `StagingFailed { path: PathBuf, source: git2::Error }` -- git2 index operation failed
     - `CommitFailed { source: git2::Error }` -- git2 commit call failed
     - `LockPoisoned` -- Mutex poisoned
     - `TaskJoin { source: String }` -- spawn_blocking join error
   - Each variant has a Display message with the fix hint embedded.

4. Create crates/ath-git/src/commit.rs:
   - `CommitMetadata` struct with fields: phase_name (String), agent_provider (String), agent_model (String), task_id (String), files_count (usize), review_status (Option<String>), reviewer (Option<String>).
   - `CommitMetadata::from_phase_data(phase_name, agent: &AgentKind, task_id, files_count, review: Option<&ReviewVerdict>)` constructor that extracts provider_name/model from AgentKind and passed/reviewer from ReviewVerdict.
   - `build_commit_message(meta: &CommitMetadata) -> String` function:
     - Subject: "athena: {phase_name}"
     - Blank line
     - Trailers: Phase, Agent (provider/model), Task-Id, Files-Count
     - Optional: Review-Status (passed/failed), Reviewer (provider/model)

5. Create crates/ath-git/src/layer.rs:
   - `GitLayer` struct with `repo: Arc<Mutex<git2::Repository>>`, `repo_path: PathBuf`.
   - `GitLayer::new(path: PathBuf) -> Result<Self, GitError>`: open if .git exists, else init. Wraps in Arc<Mutex>.
   - `GitLayer::is_dirty(&self) -> Result<bool, GitError>`: uses StatusOptions with include_untracked(true), include_ignored(false). Returns false for empty repos.
   - `GitLayer::check_conflicts(&self) -> Result<(), GitError>`: checks Index::has_conflicts().
   - `GitLayer::repo_path(&self) -> &Path`: getter.

6. Update crates/ath-git/src/lib.rs:
   - Declare modules: error, commit, layer (and later: async_ops).
   - Re-export: GitLayer, GitError, CommitMetadata, build_commit_message.

Note: Author is always Signature::now("Athena", "athena@noreply") per locked decision. Committer uses repo.signature() with fallback to Athena signature.
