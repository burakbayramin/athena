  <action>
1. Add tokio as a dependency to ath-git/Cargo.toml (only for the async wrapper):
   ```toml
   [dependencies]
   tokio = { workspace = true }
   ```

2. Create crates/ath-git/src/async_ops.rs:
   - `AsyncGitLayer` struct wrapping a `GitLayer` (owns it via Arc for cloneability, or just holds GitLayer directly since GitLayer already has Arc<Mutex> inside).
   - `AsyncGitLayer::new(path: PathBuf) -> Result<Self, GitError>`: constructs inner GitLayer.
   - `AsyncGitLayer::commit_phase_async(&self, files: Vec<PathBuf>, metadata: CommitMetadata) -> Result<CommitResult, GitError>`:
     - Clone the inner GitLayer (it's Clone-able via Arc).
     - Move into `tokio::task::spawn_blocking`.
     - Call `layer.stage_and_commit(&files, &metadata)` inside the closure.
     - Map JoinError to GitError::TaskJoin.
   - `AsyncGitLayer::is_dirty_async(&self) -> Result<bool, GitError>`: same spawn_blocking pattern.
   - Note: GitLayer needs to be Clone. Add `#[derive(Clone)]` to GitLayer (Arc<Mutex> is Clone, PathBuf is Clone -- this works). If GitLayer doesn't derive Clone from Plan 01, add it now.

3. Update crates/ath-git/src/lib.rs:
   - Add `mod async_ops;`
   - Re-export `AsyncGitLayer`.

4. Add integration tests to crates/ath-git/tests/integration.rs:

   a. `async_commit_succeeds` (#[tokio::test]):
      - Create temp repo via GitLayer, write file, use AsyncGitLayer to commit.
      - Assert committed == true.

   b. `async_initial_commit` (#[tokio::test]):
      - Empty repo, write file, async commit.
      - Assert committed == true, HEAD exists.

   c. `deletion_staged_correctly`:
      - Create temp repo, write file_a, stage_and_commit (initial commit with file_a).
      - Delete file_a from disk.
      - Call stage_and_commit with [file_a] -- should stage the removal.
      - Inspect HEAD commit tree -- file_a should NOT be present.

   d. `dirty_tree_with_untracked_file_rejects`:
      - Create temp repo, make initial commit.
      - Write a new file (untracked).
      - Call stage_and_commit with different files.
      - Assert error is GitError::DirtyWorkingTree.

   e. `conflict_detection_blocks_commit`:
      - Create a repo with merge conflicts in the index (this requires setting up a conflicting merge state using git2 directly -- create two branches modifying the same file, merge).
      - Call stage_and_commit.
      - Assert error is GitError::MergeConflict.
      - Note: If creating a real merge conflict in git2 is too complex for a unit test, create a simpler test that directly calls check_conflicts on a conflicted index. Document this approach.

5. Add `tokio` to dev-dependencies for #[tokio::test]:
   ```toml
   [dev-dependencies]
   tempfile = { workspace = true }
   tokio = { workspace = true, features = ["rt-multi-thread", "macros"] }
   ```
   (tokio is already in regular deps for async_ops, but dev-deps ensures test macros work.)
