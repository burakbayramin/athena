    - Test: missing_file_returns_error -- pass a path that doesn't exist on disk and was never tracked, get GitError::FileMissing
  </behavior>
  <action>
1. Add `CommitResult` struct to layer.rs:
   ```rust
   pub struct CommitResult {
       pub committed: bool,
       pub oid: Option<git2::Oid>,
   }
   ```
   Re-export from lib.rs.

2. Implement `GitLayer::stage_and_commit(&self, files: &[PathBuf], metadata: &CommitMetadata) -> Result<CommitResult, GitError>`:

   a. Lock the mutex (map PoisonError to GitError::LockPoisoned).

   b. Check for dirty working tree (call is_dirty logic internally, skip for empty repos).

   c. Check for merge conflicts.

   d. Stage files:
      - For each file in `files`, compute relative path via `file.strip_prefix(&self.repo_path).unwrap_or(file)`.
      - If absolute path exists on disk: `index.add_path(relative)`.
      - If not on disk: try `index.remove_path(relative)`. If that fails (file never tracked), return `GitError::FileMissing`.
      - Call `index.write()` then `index.write_tree()`.

   e. Detect empty diff:
      - If repo is NOT empty, compare new tree OID to HEAD commit's tree OID. If equal, return `CommitResult { committed: false, oid: None }`.

   f. Build signatures:
      - Author: `Signature::now("Athena", "athena@noreply")` (locked decision).
      - Committer: `repo.signature().unwrap_or_else(|_| Signature::now("Athena", "athena@noreply").unwrap())`.

   g. Build message via `build_commit_message(metadata)`.

   h. Determine parents:
      - If `repo.is_empty()`: empty vec (initial commit).
      - Else: vec containing HEAD commit.

   i. Call `repo.commit(Some("HEAD"), &author, &committer, &message, &tree, &parents)`.

   j. Return `CommitResult { committed: true, oid: Some(oid) }`.

IMPORTANT pitfalls to avoid (from research):
- Paths to index.add_path MUST be relative to repo root, not absolute.
- MUST call index.write() before index.write_tree().
- Committer signature needs fallback for environments without git config.
  </action>
