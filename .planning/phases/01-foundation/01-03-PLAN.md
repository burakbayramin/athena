    - NoConfigDir -- "Could not determine config directory"

    **file.rs:** Define a RawFileConfig struct (serde Deserialize) matching the TOML structure:

    ```
    google_api_key = "..."

    [defaults]
    claude_model = "opus-4"
    gemini_model = "2.5-pro"
    codex_model = "o3"
    ```
    All fields are Option<String>. Implement `pub fn load_config_file(path: &Path) -> Result<RawFileConfig, ConfigError>` that reads and parses the file. Return FileNotFound if file doesn't exist (not an error for optional project-local config -- caller decides).

    **env.rs:** Implement `pub fn load_env_config() -> RawFileConfig` (infallible -- missing vars are None). Read ANTHROPIC_API_KEY, GOOGLE_API_KEY, OPENAI_API_KEY from env. Call dotenvy::dotenv().ok() at the start to load .env if present (ignore errors -- .env is optional).

  <files>

  <behavior>

    - Test: Env var overrides project-local config value
    - Test: Project-local config overrides global config value
    - Test: When no config files exist and no env vars set, ConfigStore loads with all None keys (no panic)
    - Test: available_providers() returns only providers with non-None API keys
    - Test: ConfigStore with zero available providers does not error (graceful degradation)
  </behavior>
  <action>
    **store.rs:** Implement ConfigStore struct:
    ```rust
    pub struct ConfigStore {
        pub anthropic_api_key: Option<String>,
        pub google_api_key: Option<String>,
        pub openai_api_key: Option<String>,
        pub claude_model: String,     // default: "opus-4"
        pub gemini_model: String,     // default: "2.5-pro"
        pub codex_model: String,      // default: "o3"
    }
    ```

    Implement:
    - `pub fn load() -> Result<Self, ConfigError>`: The main entry point. Calls global_config_path(), loads global file (ok if missing), loads project-local .ath.toml (ok if missing), loads env vars, merges with correct precedence.
    - `fn load_from_layers(global: Option<RawFileConfig>, local: Option<RawFileConfig>, env: RawFileConfig) -> Self`: Merge logic. For each field: env.field.or(local.field).or(global.field). Model fields fall back to defaults if not specified.
    - `fn global_config_path() -> Result<PathBuf, ConfigError>`: Uses dirs::config_dir() to get ~/.config/ath/config.toml (cross-platform).
    - `pub fn available_providers(&self) -> Vec<&str>`: Returns list of provider names that have API keys configured. Used by downstream code to know which agents are available.
    - `pub fn has_any_provider(&self) -> bool`: At least one API key is configured.

    **lib.rs:** Declare modules (pub mod store, file, env, error). Re-export ConfigStore and ConfigError at crate root.

    For testability, add a `load_from_layers` that accepts pre-loaded config layers so tests don't need real files or env vars. The `load()` method calls the real I/O functions then delegates to `load_from_layers`.

    Write inline tests for merge logic and an integration test in tests/ directory that exercises the full load path with temp files (use std::fs::write to a temp dir).
