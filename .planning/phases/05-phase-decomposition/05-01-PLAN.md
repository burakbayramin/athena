  <files>crates/ath-planner/src/decompose/mod.rs, crates/ath-planner/src/decompose/dag.rs, crates/ath-planner/src/decompose/error.rs, crates/ath-planner/src/lib.rs</files>
  <behavior>
    - topological_sort on linear chain [A->B->C] returns [A, B, C]
    - topological_sort on diamond [A->B, A->C, B->D, C->D] returns valid order (A before B,C; B,C before D)
    - topological_sort on cycle [A->B->C->A] returns Err with cycle path containing all three IDs
    - topological_sort on disconnected [A, B] (no deps) returns both in some order
    - compute_parallel_groups on diamond returns [[A], [B, C], [D]] (3 groups)
    - compute_parallel_groups on linear returns [[A], [B], [C]] (no parallelism)
    - critical_path_length on diamond returns 3 (A->B->D or A->C->D)
    - critical_path_length on single phase returns 1
    - find_cycle_path on A->B->C->A returns path containing A, B, C
  </behavior>
  <action>
    Create `crates/ath-planner/src/decompose/` directory with:

    **error.rs**: DecomposeError enum with thiserror:
    - `DecomposeFailed { attempts: usize, last_error: Option<String> }` -- #[error("Decomposition failed after {attempts} attempts")]
    - `Agent(#[from] ath_agents::error::AgentError)` -- #[error("Agent error: {0}")]
    - `Validation(Vec<ath_types::ValidationError>)` -- #[error("Validation errors: {0:?}")]

    **dag.rs**: Pure graph algorithms operating on `&[PhaseSpec]`:
    - `pub fn topological_sort(phases: &[PhaseSpec]) -> Result<Vec<u32>, Vec<u32>>` -- Kahn's algorithm. Returns sorted IDs on success, cycle path on failure. Uses HashMap<u32, usize> for in-degree, HashMap<u32, Vec<u32>> for adjacency, VecDeque for BFS queue. If sorted.len() != phases.len(), call find_cycle_path to get the actual cycle.
    - `fn find_cycle_path(phases: &[PhaseSpec]) -> Vec<u32>` -- DFS-based cycle finder. Uses color marking (White/Gray/Black). When a Gray node is revisited, backtrack the recursion stack to extract the cycle. Return the cycle as a Vec<u32> of phase IDs.
    - `pub fn compute_parallel_groups(phases: &[PhaseSpec], sorted_order: &[u32]) -> Vec<Vec<u32>>` -- Level assignment: each phase's level = max(level of deps) + 1, roots at level 0. Group by level. Return Vec<Vec<u32>>.
    - `pub fn critical_path_length(phases: &[PhaseSpec], sorted_order: &[u32]) -> usize` -- Longest path: each phase's path = max(path of deps) + 1, roots at 1. Return max across all phases.
