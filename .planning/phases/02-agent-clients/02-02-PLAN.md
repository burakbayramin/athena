**crates/ath-agents/src/actor/mod.rs:** Create the shared actor infrastructure module:

1. `ActorMessage` struct: `request: AgentRequest`, `respond_to: oneshot::Sender<Result<AgentResponse, AgentError>>`.

2. `classify_error(err: genai::Error, provider: &str) -> AgentError` function:
   - Match on genai error variants. For `genai::Error` (check actual enum at compile time):
   - Look for HTTP status codes: 429 -> RateLimit, 401/403 -> AuthFailed, 5xx -> ServerError
   - Timeout variants -> Timeout (use 5min default duration in the error)
   - Parse/deserialization failures -> InvalidResponse
   - Auth-related genai errors (RequiresApiKey, NoAuthData) -> AuthFailed
   - Everything else -> Unknown
   - NOTE: genai error enum variants may differ from what research predicted. Inspect the actual genai::Error type at compile time and adapt. The mapping intent is clear -- classify by retryability.

3. `build_genai_client(config: &ConfigStore) -> Result<genai::Client, AgentError>` function:
   - Use `genai::Client::builder()` with `AuthResolver::from_resolver_fn()`.
   - The resolver closure captures cloned API keys from ConfigStore.
   - Match on `model_iden.adapter_kind` to return the correct key. Check genai docs for `AdapterKind` enum variant names (likely `AdapterKind::Anthropic`, `AdapterKind::GoogleGemini`, `AdapterKind::OpenAI` or similar).
   - If the key for a provider is None, return an auth error from the resolver.
   - This function is called once at actor startup.

4. `call_provider(client: &genai::Client, model: &str, prompt: &str, context: Option<&str>, provider: &str) -> Result<(String, u64, u64), AgentError>` function:
   - Build a `ChatRequest` from prompt + optional context as system/user messages.
   - Set `ChatOptions` with `with_response_format(ChatResponseFormat::JsonMode)` -- NO, actually only set JSON mode when needed. For v1, keep it simple: just send the prompt as a user message, get text back. JSON mode is an optimization the caller can request later.
   - Actually, per CONTEXT.md: "Agent layer validates that response is valid JSON when JSON mode was requested." For now, just send prompt as text, return content as string. JSON validation is a concern for a flag on AgentRequest (not yet defined -- out of scope for this phase).
   - Call `client.exec_chat(model, chat_req, None).await`.
   - Extract content string, input_tokens, output_tokens from the response.
   - Map genai errors via `classify_error()`.
   - Return `(content, input_tokens, output_tokens)`.

5. `run_with_retry_and_breaker(client: &genai::Client, model: &str, request: &AgentRequest, circuit_breaker: &mut CircuitBreaker, provider: &str) -> Result<AgentResponse, AgentError>` function:
   - Check `circuit_breaker.can_attempt()` -- if false, return `AgentError::CircuitOpen`.
   - Use `backon::ExponentialBuilder` with: min_delay 1s, max_delay 60s, factor 2.0, jitter, max_times 3.
   - The retry closure calls `call_provider()`.
   - Use `.retry(backoff).when(|e| e.is_retryable()).await`.
   - On success: `circuit_breaker.record_success()`, build and return `AgentResponse`.
   - On failure: `circuit_breaker.record_failure()`, return the error.
   - Set per-request timeout of 5 minutes using `tokio::time::timeout()` wrapping the entire retry sequence.

Make `actor` module public. Re-export actor handle types from `actor/mod.rs`.

**For each of claude.rs, gemini.rs, codex.rs:**

1. Define `{Provider}Actor` struct:
   - `receiver: mpsc::Receiver<ActorMessage>`
   - `client: genai::Client`
   - `circuit_breaker: CircuitBreaker`
   - `model: String`
   - `provider: String` (for error messages)

2. Define `{Provider}Handle` struct (Clone):
   - `sender: mpsc::Sender<ActorMessage>`
   - `circuit_breaker_open: Arc<AtomicBool>` -- lightweight status flag updated by actor

3. `{Provider}Handle::new(config: &ConfigStore) -> Result<Self, AgentError>`:
   - Validate that the relevant API key is Some, return AgentError::AuthFailed if None (fail-fast per user decision).
   - Call `build_genai_client(config)` to create the genai client.
   - Create bounded mpsc channel (buffer: 32 per user decision).
   - Spawn the actor via `tokio::spawn(actor.run())`.
   - Return the handle.

4. Actor `run()` loop:
   - `while let Some(msg) = self.receiver.recv().await`
   - Call `run_with_retry_and_breaker()` with the request.
   - Update the `circuit_breaker_open` AtomicBool flag.
   - Send result back via `msg.respond_to`.

5. `#[async_trait] impl AgentBackend for {Provider}Handle`:
   - `send()`: Create oneshot, send ActorMessage, await response. Map channel errors to ActorStopped.
   - `is_available()`: Read the AtomicBool flag (non-blocking).
   - `provider_name()`: Return static string.
